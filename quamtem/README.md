# KP Chart (polder)

KP Astrology Chart එකක් නිර්මාණය කිරීම සඳහා HTML, CSS, සහ JavaScript භාවිතා කරන open-source project එකකි. මෙය KP Astrology (Krishnamurti Paddhati) ප්‍රායෝගිකව අධ්‍යයනය සහ ආරම්භකයන්ට KP Chart නිර්මාණය කිරීම පහසු කිරීම සඳහා සැලසුම් කර ඇත.

## 🚀 Quick Start

1. **kp-chart.html** file එක browser එකක open කරන්න.
2. Data dynamic ලෙස දක්වන්නට JavaScript (උදා: index.js) භාවිතා කළ හැක.
3. KP chart එක browser එක තුළ visualize කරන්න.

---

## 🛠️ Development Guide

- **Chart UI වෙනස් කිරීමට**: `kp-chart.html` file එක edit කරන්න.
- **Data automate කිරීමට**: JavaScript file එකක් (උදා: `index.js`) එක් කරන්න.
- **Styles වෙනස් කිරීමට**: HTML file එකේ CSS section එක හෝ වෙනම CSS file එකක් edit කරන්න.
- **New features**: ඔබට අවශ්‍ය columns, data bindings, API integrations එකතු කරන්න.
